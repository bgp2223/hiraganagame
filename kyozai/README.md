# 教材置き場（kyozai）

授業や作業で使う教材（プリント、図、PDF など）をまとめておくフォルダです。

## フォルダの分け方

```
kyozai/
  教科/
    単元・テーマ/
      できあがったもの（PDF・SVG）
      作り直し用のファイル（make.py など）
```

## 中身

| フォルダ | 内容 |
|---|---|
| `数学/立方体の切断/` | 立方体と正八面体、正三角形・正六角形の切り口（ベクター図、A4横PDF） |

面積迷路は、リポジトリ直下の `menseki-meiro.html` と `menseki-meiro-pdf/` にあります。

## 図を作り直すとき（立方体の切断）

```
cd kyozai/数学/立方体の切断
python3 make.py      # SVG と sheet.html を作る
node pdf.js          # 立方体の切断_4図.pdf を作る（Playwright が必要）
```

頂点の名前の位置や線の太さ、切り口の色は `make.py` の先頭近くで変えられます。
